# Security Policy

本项目是不含账号系统的静态索引。请不要在 Issue 中公开 token、Cookie、账号信息或其他敏感数据。

如发现刷新脚本、依赖链或页面存在安全问题，请通过 GitHub 私下联系维护者 [@joeseesun](https://github.com/joeseesun)。

The project is a static catalog with no account system. Do not disclose tokens, cookies, credentials, or other sensitive data in public issues.
